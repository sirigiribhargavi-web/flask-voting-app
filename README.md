# Flask Voting Application

## 📖 Project Description
This project is a simple web application built using **Flask**.  
It provides different URLs that perform different tasks.  

- **Version 1** contains:
  - A welcome page (`/`)
  - A health‑check page (`/health`) to verify that the application is running correctly  

The project is maintained using Git branches to keep stable code separate from development work.
